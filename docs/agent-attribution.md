# Agent Attribution Policy

This repository uses neutral attribution for content produced inside the repository. The policy applies to
agent-written documentation, reports, reviews, status records, and workflow messages.

## Use Neutral Roles

Use role labels such as:

- `contributor`
- `reviewer`
- `agent`
- `maintainer`

Do not identify an agent-generated repository artifact with a model/provider name, commercial identity, logo,
marketing signature, or generated-by watermark. The repository should describe what was changed and verified,
not advertise which commercial tool produced it.

## Preserve Human Attribution

Do not rewrite or remove existing human-authored names, copyright notices, license text, signed commits, or
historical review records. Neutral agent attribution is not a reason to erase authorship or provenance.

## Platform Boundary

The repository controls tracked content and instructions supplied to repository workflows. It cannot remove a
watermark or branding injected by an external Claude interface, API gateway, GitHub integration, or
organization-managed platform after content leaves the workspace. Administrators must use that platform's
documented settings when external branding needs to change.

Technical documentation may mention a provider when the name is necessary to describe a real configuration or
integration boundary. That factual reference is different from attributing repository work to the provider or
adding commercial promotion.
