# Neutral Repository Attribution

When producing content for this repository:

1. Identify work with neutral roles such as `contributor`, `reviewer`, `agent`, or `maintainer`.
2. Do not add model/provider names, commercial identities, logos, marketing signatures, or generated-by
   watermarks to new repository content.
3. Preserve existing human-authored attribution, copyright, licensing, and historical review records.
4. Mention a provider only when it is a necessary factual part of technical configuration or an integration
   boundary, never as promotional or authorship language.
5. Remember that branding injected by an external UI, API gateway, or organization platform is outside this
   repository's control; do not alter repository provenance to conceal it.

Review generated text before writing it to a tracked file, commit message, report, or review.
