# Roadmap

This roadmap orders future capabilities and teaches the intended growth path. OpenSpec changes contain
detailed requirements and tasks; this file contains only sequencing, status, and links to the governing
contract.

## Milestone Tracking

| Phase                            | Governing changes                   | Status   |
| -------------------------------- | ----------------------------------- | -------- |
| Foundation                       |                                     | Complete |
| Agent harness and MCP governance | `improve-agentic-boiler-governance` | Complete |

The initial foundation is represented by accepted specs and the runnable `hello` project. The governance
milestone is complete because its change is archived and its accepted requirements are present. Future work
must add and strictly validate a pending OpenSpec change before adding a roadmap row. A row points to the
governing change; it never duplicates that change's requirements or task checklist.
