# Maintainers

## Ownership

The repository owner, [@salzayat](https://github.com/salzayat), is the initial maintainer and default
code owner. `.github/CODEOWNERS` is the review-routing source of truth.

Maintainers are responsible for keeping accepted specs, implementation, checks, and documentation aligned;
reviewing dependency updates; and protecting the repository's credential-free, local-only examples.

## Adding Maintainers

Add maintainers through a reviewed pull request that updates this file and `.github/CODEOWNERS`. Do not
grant repository administration or external-system authority through agent configuration.
